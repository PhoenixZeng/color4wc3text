# ColorPicker

这是一个 VS Code 拓展。

它使得魔兽争霸3的字符串前缀可以被颜色选择器识别和修改，后续也支持了一些常规的格式。

## 环境要求

- VS Code 1.137.0 或更高版本。
- 开发环境使用 Node.js 22.12.0 或更高版本。

## 开发验证

运行 `npm ci` 安装锁定的依赖，使用 `npm test` 通过本机 VS Code 执行编译、lint 和扩展测试，使用 `npm audit` 检查依赖安全。

`package.json` 中的 `overrides` 将测试工具链的 Mocha、glob、minimatch 固定在已修复安全问题的主版本范围；待上游测试工具支持这些版本后可移除相应覆盖。请保留并同步提交 `package-lock.json`。

测试默认查找 PATH 中的 `code` 命令，不自动下载 VS Code。非标准安装可用环境变量 `VSCODE_EXECUTABLE_PATH` 指定可执行文件；在 VS Code 中选择“Extension Tests”运行时会自动使用当前编辑器。测试数据存放在独立的 `.vscode-test` 目录，不使用日常用户配置。只有显式设置 `VSCODE_TEST_VERSION` 才下载指定测试版本（例如验证最低支持版本 1.137.0）。

## 颜色回写设置

在 VS Code 设置中搜索 `color4wc3text`，支持用户及工作区设置，修改后下一次回写立即生效。

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| `color4wc3text.floatPrecision` | `3` | RGBA 透明度按指定小数位数四舍五入（0–20），去掉末尾无意义的 0；0.1236 → 0.124，0.0004 → 0，0.4 → 0.4。 |
| `color4wc3text.hexCase` | `auto` | `uppercase` 大写、`lowercase` 小写、`auto` 自动。自动模式从目标颜色代码左侧寻找第一个 A–F 字母，按其大小写输出；纯数字代码采用大写。 |

大小写设置作用于 War3 HEX 和 CSS HEX 的颜色数字部分，保留 War3 的 `|c`／`|C` 前缀、正文及 `|r` 后缀。例如自动模式下 `#12aB00` 输出小写，`#12Ab00` 输出大写。

## War3 文字预览（试用）

预览和 **标准化** 只出现在 War3 颜色代码／色块的共用 Hover 面板中。选中文字不会自动弹出面板，悬停正文也不会单独显示预览。选区不会改变正文边界。

仅在当前语言能明确识别完整正文时显示预览；范围不明确、注释或未闭合字符串不回退到整行。

| 语言 | 正文边界 |
| --- | --- |
| Lua | 单引号、双引号及跨行 `[[...]]`、`[=[...]=]` 等同级长括号；排除 `--` 短注释与长注释。 |
| JASS / vJASS / Zinc | 双引号字符串，处理反斜杠转义；排除注释和单引号原始代码。 |
| INI / LNI | `=` 后的值：有引号则只取引号内，无引号则取值到行尾／注释前；支持长括号及表中的独立字符串，排除键名、节名、注释。INI 模式兼容常见 LNI 写法，`.lni` 文件可直接使用 LNI 语言模式。 |
| XML | 元素内的独立文本节点、单／双引号属性值及 CDATA；支持跨行，不跨子节点，排除注释、处理指令和 DTD。 |
| JSON | 合法 JSON 文档中的字符串值，不预览对象键。 |
| JavaScript / TypeScript | 单／双引号字符串和无插值的静态模板；排除注释、常见正则字面量及动态模板。 |
| FDF | 双引号字符串，排除注释。 |

预览按当前文本的颜色切换顺序显示：`|r` 恢复默认色，不模拟颜色嵌套。支持 `|n` 换行及 `||` 字面竖线；使用编辑器字体和默认前景色，忽略 War3 颜色中的 AA，不保证与游戏字体、背景完全一致。普通字符串按语言解码引号、换行等转义，XML 文本和属性解码内置实体及数字字符引用；Lua/LNI 长字符串与 XML CDATA 保留原文。不会执行代码或计算动态拼接。

**标准化** 以图标和加粗链接单独放在预览底部，操作会在下一颜色开始前及当前正文末尾补齐缺少的 `|r`，保留正文、原有标记、大小写和外层定界符。不会恢复外层颜色，也不删除已有的多余 `|r`。操作可一次撤销。

例如 `"|cFFFF0000红|cFF00FF00绿"` 会变成 `"|cFFFF0000红|r|cFF00FF00绿|r"`。正文后接其他动态拼接内容时，补齐末尾 `|r` 会终止向后延续的颜色。

面板已采用紧凑布局，去掉独立标题和重复说明。原生 Hover 的高度上限由 VS Code 控制，扩展无法直接取消它的滚动条；仍有滚动时可以拖动 Hover 边缘调高。Unicode 字符提示也可能同时出现，本扩展不更改相关检测设置。

## 支持以下语法

```txt
War3 语法
     - |cAARRGGBB (支持 |c 和 |C，修改后按设置输出大小写，并完美保留 |r 后缀)
     
color 函数 (支持 3 个或 4 个参数)
     - color(255, 0, 0)
     - color(255, 0, 0, 255)
     - 支持十六进制写法 color(0xFF, 0x00, 0x00)
     - 大写开头 Color 也可识别

rgb / rgba 函数
     - rgb(255, 0, 0)
     - rgba(255, 0, 0, 0.5)
     - 大写开头也可识别

CSS HEX 颜色
     - #FFF
     - #FFFF (带透明度)
     - #FFFFFF
     - #FFFFFFFF (带透明度)
```
