# ColorPicker

这是一个 VS Code 拓展。

它使得魔兽争霸3的字符串前缀可以被颜色选择器识别和修改，后续也支持了一些常规的格式。

## 支持以下语法

```txt
War3 语法
     - |cAARRGGBB (支持 |c 和 |C，修改后自动统一大写，并完美保留 |r 后缀)
     
color 函数 (支持 3 个或 4 个参数)
     - color(255, 0, 0)
     - color(255, 0, 0, 255)
     - 支持十六进制写法 color(0xFF, 0x00, 0x00)
     - 大写开头 Color 也可识别

rgb / rgba 函数
     - rgb(255, 0, 0)
     - rgba(255, 0, 0, 0.5)
     - 大写开头也可识别

CSS HEX 颜色
     - #FFF
     - #FFFF (带透明度)
     - #FFFFFF
     - #FFFFFFFF (带透明度)
```

## 目前支持以下后缀格式的文件

> 注：`css` 和 `html` 文件由 VS Code 原生自带颜色识别功能，本插件不再重复注册。
